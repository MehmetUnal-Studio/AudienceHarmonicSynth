Atomic spectral scale clustering

From atomic spectra to a playable musical scale

Audience Harmonic Synth separates each element's emission lines into two musical roles: the complete raw spectrum remains available as timbre, while the playable scale is reduced by clustering nearby spectral lines.

No raw data is lost Every spectral line remains available as a timbre partial.
The scale becomes playable Very close lines are grouped into one pitch family.
MPE preserves tuning Microtonal targets are emitted as note plus pitch bend.
Beryllium Core Mode 380-750 nm / 0-1200 ct

01 / Problem

Why clustering is necessary

Atomic emission spectra contain wavelength and relative intensity information. Sparse elements such as hydrogen contain only a few strong lines. Dense elements such as iron, sodium, or sulfur can contain dozens or hundreds of visible-region lines.

If every line is converted directly into a playable pitch, a single octave can become crowded with extremely close microtonal notes. Some lines land within 10-20 cents of one another. These intervals are often perceived less as separate scale degrees and more as shimmer, beating, or metallic movement inside the timbre.

Core idea: do not delete spectral data; change its musical role. Nearby lines become one playable scale degree, while every source line continues to live inside the timbre.
Timbre / Scale separation two layers
Raw spectrum

All wavelengths and intensity values from the element dataset are preserved.

Timbre partials

Every line becomes an additive or spectral partial in the atomic tone color.

Playable scale

Nearby pitch-class lines are clustered and represented by a selected scale degree.

02 / Algorithm

From wavelength ratio to pitch family

First, the longest valid wavelength of the selected element is treated as the reference line. This line becomes the musical root. All other lines are measured against that reference.

ri = λref λi

The ratio is converted into a musical distance in cents, then folded into one octave.

Ci = ( 1200 ⋅ log2 ( ri ) ) mod 1200

Because octave pitch space is circular, distance is not measured as a simple linear difference. 0 cents and 1200 cents describe the same pitch-class point.

d (a,b) = min ( |a-b| , 1200-|a-b| )
Step 1

Normalize

Angstrom and nanometer input is normalized so all lines live in nm.

Step 2

Reference

The longest wavelength is selected as the root line and reference wavelength.

Step 3

Pitch class

Each line is converted into a ratio and cent value, then folded into one octave.

Step 4

Salience

Intensity is log-compressed and normalized to determine selection priority.

Step 5

Cluster

Nearby pitch-class lines are assigned to the same pitch family.

Step 6

Representative

A real source line is selected from each cluster as the representative scale degree.

03 / Reduction modes

One algorithm, multiple musical densities

The same atomic data can be opened at different levels of detail. Core mode is the cleanest version for composition and performance. Raw mode performs no reduction and exposes the full scientific line set.

Max degree 7
Min distance 80 ct
Use case Melodic

05 / Representative selection

Selecting a real line from each cluster

To represent the center of a cluster, the system uses the medoid approach by default. The medoid is the real spectral line with the smallest weighted distance to the other lines in the cluster.

This avoids inventing artificial pitches. The result is always grounded in an actual wavelength from the element dataset, so the scale remains musically legible without losing its physical spectral origin.

Representative modes options

Strongest

Selects the highest-intensity line inside the cluster.

Medoid

Selects the real line closest to the weighted center of the cluster. This is the default.

Weighted mean

Uses a circular weighted mean. It is smooth, but it can create an artificial pitch.
